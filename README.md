# 🐍 API REST em Python (Flask)

API REST simples desenvolvida em Python utilizando o microframework Flask para disponibilizar rotas de consulta de produtos em formato JSON.

---

## 📌 Rotas da API

* `GET /produtos` - Retorna a lista de produtos cadastrados.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**
* **Flask**

---

## 💻 Como Executar o Projeto

1. Certifique-se de ter o Python instalado.

2. Instale o Flask no terminal:
   ```bash
   pip install flask
   ```
3. Execute a aplicação
   ```bash
   python app.py
   ```
4. Acesse http://127.0.0.1:5000/produtos no seu navegador para visualizar os dados.
